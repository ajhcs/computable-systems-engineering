# CSE engineering components

Use [the component guide](../../docs/component-library.md) for selection, SysML/SysE contexts, Draw.io imports and the Kernspan adapter. `components/` contains one editable SVG per stable ID; `index.json` contains the per-ID records and assembly membership. `tokens/` retains color, typography and routing specifications. `sources/` contains attributed source records and byte-preservation evidence.

The complete saved palette is available as `palette.pdf` and `palette.svg`. Original approval statuses remain explicit. Saved variants are available together, with no exclusive default. Geometry and labels can be edited in the standalone SVGs; images in the screen atlas are presentation derivatives.
