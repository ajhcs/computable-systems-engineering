# Electrical symbol visual references

Each item lists the actual figure or product illustration inspected before refinement, the features retained, and the scope of the adaptation. Descriptions are drawn from the contributors’ frozen reference ledgers. Source documents are linked, not embedded.

A reference is evidence of a particular example and its depiction; it does not establish conformance to a controlled electrical standard or suitability for a real installation.
