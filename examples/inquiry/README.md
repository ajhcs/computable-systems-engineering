# Original question-to-model examples

Each source brief supplies an original hypothetical engineering question, proposed workload/minimums, alternative means and explicit unknowns. The adjacent native model contains the authoritative bounded inquiry record. No figures or rates are copied from academic sources, vendor specifications or private notes; none is a measured performance or accepted requirement.

Use [the workflow and record contract](../../docs/inquiry-profile.md). The skill handles modeling and commands for the engineer. Begin with known facts; an incomplete question is a legitimate draft.
