# Controlled-English pump study

The synthetic native model uses `pump` as a defined technical noun and `isolate`
as a defined technical verb. The sibling `shared-pump.english.json` reuses the
existing foundation vocabulary and binds exact noun/verb uses to the same native
engineering IDs. The English profile runs automatically with each drafting
skill's normal `check` command, including draft/syntax-only checks.

The [language skill contract](../../skills/check-engineering-language/references/controlled-english.md)
documents selected STE coverage, project rules, revision pins, preserved source
spans, and supported repair comparisons. This example creates no real-system
requirement, translation or engineering acceptance.
