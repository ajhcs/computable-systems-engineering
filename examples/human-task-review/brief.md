Synthetic service-desk human-task study. All roles, durations, skills and training below are proposals, not field measurements.
The boundary is request review and recovery of interrupted request review using an existing application.
Normal operation has a clerk reviewing a request with application assistance.
Peak demand keeps one request active per clerk; additional work is queued and no simultaneous capacity is asserted.
Absence uses a proposed backup clerk; actual availability and competence are unqualified.
Recovery rechecks request state after an interruption before continuing.
Each selected task needs a stated entry condition, inputs, completion condition, skills, equipment, procedure,
proposed duration, concurrency limits, interruption/recovery handling, training and an evaluation plan.
No automatic person-versus-automation choice, staffing verdict, task-network simulation or fatigue model is selected.
