# Selected ecosystem diagram references

This release includes three attributed engineering derivatives: NASA maintenance scheduling (C), NIST Smart Grid domain interactions (D), and selected APE interface allocations (E). [Open the gallery](gallery.html). A bank process and a healthcare process remain held because adaptation rights are unresolved; their models, facts and graphics are absent. Requesting either held case in the checker fails explicitly.

| Case | Retained meaning | Boundaries |
| --- | --- | --- |
| C — [maintenance](rendered/C-maintenance.png) | Eleven tasks, source crew codes and hour quantities; 3.6 task-hours and 1.0 hour elapsed | Starts are chart readings at 0.1-hour resolution. Crew codes do not prove staffing counts; no cross-crew dependency, safety or real maintenance validation is inferred. The printed “food strainer” wording is retained. |
| D — [Smart Grid](rendered/D-smart-grid.png) | Seven domains, 15 undirected communication relationships shown in 30 symmetric cells, and three undirected electrical connections | The source's “secure” legend is not security verification. View contexts and adapter ports do not assert physical ownership or interfaces. |
| E — [APE allocation](rendered/E-ape-allocation.png) | Six named endpoints and four directed allocations, shown in eight mirrored cells | The UML interface is represented by an explicitly introduced port usage. Proxy-port, payload and protocol semantics are incomplete. No blank source row, extra port or connectivity is invented. |

Each retained case has a scoped SysML v2 model, previously recorded linked facts from that model, a bounded derivative fact ledger, SVG/PNG presentation, view geometry and editable draw.io companion. These are explanatory presentations, not formal graphical-conformance, execution or native-editor qualification. The ledgers summarize selected reviewed facts; they are not raw source model records or an authoritative replacement for upstream sources. Source identifiers remain trace locators.

The release retains existing SVG and PNG bytes. Their visible “Review 03” label describes the historical presentation revision. No new browser rendering, font-box validation or human visual review was run for this release; old all-five-case receipts are not shipped. The E footer's Cookbook figure citation is historical context. The retained E endpoint/allocation facts were independently matched to the Apache-licensed APE archive; that license does not license the Cookbook publication. See [release status](release.json), [source locators](source/sources.json), [attribution and licenses](notices/README.md), and each source ledger's limits.

From the repository root, run `python3 -B scripts/check_ecosystem_references.py` for bounded artifact, fact, unit, direction and geometry correspondence. It requires all three retained cases and does not parse upstream XML, acquire sources or start a browser. It also checks that recorded parser facts still bind to the supplied model bytes. A passing result is not a fresh parser run or a source-authenticity verdict.

For a future requested layout change, `python3 -B examples/ecosystem-diagram-reference/tools/render.py --output /absolute/path/to/new-output` generates new SVG/geometry/notes outside this curated directory. It does not overwrite these assets or render PNGs. The E renderer now uses model archive attribution in its footer, so its future SVG differs from the retained historical SVG. Browser qualification is a separate optional tool requiring an explicitly supplied installed browser and a new output directory; it was not invoked for this release. Do not bypass a denied browser action.

The draw.io files carry geometry and native identifiers; they do not promise SVG font/texture fidelity or SysML interchange. Native-tool load/save/reopen and engineering acceptance remain unrun.

`tools/EcosystemReferenceProbe.java` is an optional source adapter for the already installed SysML pilot runtime, not a bundled parser or an automatically executed checker. Its arguments are `REFERENCE_ROOT LIBRARY_ROOT NEW_OUTPUT_DIRECTORY [EXACT_CASE]`; the output parent must already exist, and only exact C/D/E case names are accepted. It rejects held/unknown cases and writes newly generated facts outside the curated pack. Changing a model requires separately qualifying new parser facts and presentations; the release checks cannot supply that qualification.
