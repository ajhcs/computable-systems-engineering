# NIST electronics MakeCoupler — text and fact ledger

This release contains the selected activity's bounded derivative fact ledger and an engineering reading, with the complete source notice. It inventories 17 calls, 16 directed ControlFlow edges, 33 input pins, 25 output pins, two activity parameter nodes and two owned activity parameters. It does not bundle the original model or any graphic. The previous SVG/PNG, draw.io and mapping are held together because their visible statement that a native model accompanies them would be false here; no fresh rendering was authorized.

The ledger orders the 17 distinct call instances. Inputs calls GetInputs_Coupler and exposes nine typed component outputs. UnitAssembly calls Assemble with an input typed Part and an output typed Coupler. Assembly and manual inspection alternate before leak checking and functional testing. Vibration, burn-in and final-data tests follow, then manual verification, laser marking, touch-up, two separately named final-sell inspections and PutOutputs_Coupler. Distinct call instances remain distinct even when they call the same behavior, such as Assemble or ManualInspect.

The 16 recorded ControlFlow edges order calls. The selected source has no ObjectFlow edges, so neither parts nor work orders are carried by those arrows. Every pin and both activity parameter nodes remain unwired in the selected activity. workOrderIN is untyped in the source and remains untyped. Recorded multiplicities are 1. Do not fill these gaps to make the drawing appear more executable.
